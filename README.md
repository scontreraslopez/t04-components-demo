# T04 · Components Demo

Proyecto de ejemplo del **T04 (Estado, TextField, elevación de estado, Switch, Checkbox, RadioButton)** del módulo PMDM.

Cada componente está en su propio fichero, es **sin estado** (*stateless*) y recibe el valor y el evento desde fuera. El estado vive en `T04ComponentsDemoApp`. Es el patrón de **elevación de estado** (*state hoisting*) que se explica en los apuntes.

> [!TIP]
> El repositorio está hecho con **commits progresivos**: cada commit añade un componente. Si os perdéis, id a la pestaña *Commits* y mirad el *diff* de cada paso en lugar de leer el proyecto final de golpe.
